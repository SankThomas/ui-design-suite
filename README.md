# UI Design Suite

A collection of modern user interface designs and frontend implementations built to explore UI patterns, improve frontend development skills, and turn design concepts into functional web experiences.

**Live Demo:** [tsbuidesignsuite.vercel.app](https://tsbuidesignsuite.vercel.app/)

**Repository:** [SankThomas/ui-design-suite](https://github.com/SankThomas/ui-design-suite)

All designs come from [UI Design Daily](https://uidesigndaily.com)

## Overview

This repo is a collection of frontend UI projects built with modern web technologies (mostly React and TypeScript). It serves as a workspace for experimenting with interface layouts, reusable styling patterns, responsive designs, and interactive components.

Each project provides an opportunity to practice translating design concepts into clean, maintainable, and functional frontend code.

## Features

- **Modern UI Designs:** A growing collection of interface concepts and implementations.
- **Component-Based Architecture:** Build interfaces using reusable React components.
- **Responsive Layouts:** Develop interfaces that adapt to different screen sizes.
- **Utility-First Styling:** Use Tailwind CSS to create consistent and maintainable designs.
- **Interactive Interfaces:** Implement functional UI elements and navigation.
- **Modern Icons:** Use Lucide React for clean, consistent iconography.
- **Type Safety:** Use TypeScript to improve code reliability and maintainability.

## Tech Stack

| Technology      | Purpose                              |
| --------------- | ------------------------------------ |
| React           | Component-based user interfaces      |
| TypeScript      | Static typing and maintainable code  |
| Vite            | Development server and build tooling |
| Tailwind CSS v4 | Utility-first styling                |

## Getting Started

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm, pnpm, or another compatible package manager

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SankThomas/ui-design-suite.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ui-design-suite
   ```

3. Navigate to a single project:

   ```bash
   cd profile-card-2
   ```

4. Install the dependencies using your preferred package manager:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm dev
   ```

6. Open the local URL displayed in your terminal to view the application. (Usually [http://localhost:5173](http://localhost:5173))

## Available Scripts

| Command           | Description                                     |
| ----------------- | ----------------------------------------------- |
| `npm run dev`     | Start the Vite development server               |
| `npm run build`   | Run TypeScript checks and build the application |
| `npm run lint`    | Check the code using Oxlint                     |
| `npm run preview` | Preview the production build locally            |
